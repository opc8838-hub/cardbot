## 接入层的真实能力

- Mock：能产生模拟保存回执，不能登录小满查到，不具有远端保存证明力。
- 官方 API：小满开放平台和 OAuth 取 token 方式已确认；现有代码仍只是按配置执行 Bearer POST 的通用适配器，尚未实现凭证换 token、刷新和业务端点映射。公开权限列表含客户、线索、商机、用户、仓库、报表、Webhook 等，未看到邮件草稿权限；不能据此宣称草稿 API 可用。
- RPA：没有实际页面驱动时返回未就绪；需要授权账号、允许自动化的确认、选择器与独立 Worker。
- 后端本地草稿：落 JSON 文件；不是多实例事务数据库。并发写、版本历史、远端失败补偿与审计仍需完善。

- 全球城市坐标是内置参考；尚未做真实客户地址标准化/地理编码/隐私授权。
